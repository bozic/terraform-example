All notable changes to this module will be documented in this file.

## [1.0.0] - 2026-09-02

### Added

- Initial release of the Azure Virtual Network module.
- Create-or-query support for Virtual Networks.
- Support for zero or more standalone subnets with optional Network Security Group and Route Table associations.
